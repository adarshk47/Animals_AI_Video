# Motion Library

Paste these into the **video prompt** field of a prompt card. Combine one motion with a camera move and a background from `backgrounds.md`.

Tips:
- One main action per clip. Do not ask for walk + roar + jump in a single 5-10s clip.
- Name the camera: `static camera`, `slow tracking shot`, `low angle`, `handheld follow`.
- For talking shots use `[animal] facing camera, mouth moving as if speaking, subtle head movement` and keep the body mostly still. This works best with lip-sync.

## Lion
| Motion | Prompt |
|--------|--------|
| Walk | `lion walking slowly and confidently toward camera, powerful shoulders rolling, mane moving, slow tracking shot` |
| Roar | `lion standing, opens mouth wide and roars, mane vibrating, static low-angle camera` |
| Rest | `lion lying down in the shade, slow breathing, ears flicking, static camera` |
| Talk | `lion facing camera, mouth moving as if speaking, calm head movement, medium close-up` |

## Two animals in one shot
`[animal A] on the left and [animal B] on the right, facing each other as if talking, static medium shot`

Animals interacting is harder for AI video tools. If it fails, generate each animal separately and cut between them (shot / reverse shot).
