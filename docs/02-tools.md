# Tools

This kit does not depend on one specific product. Pick one tool per category. Features, limits and prices change often, so check each tool's current page before paying. The tool names below are examples, not endorsements, and I have not verified their current prices or Hindi support.

## Image generation (step 3)
Needs: consistent characters (reference image support), 9:16 and 16:9 output.
Examples: Midjourney, Google Imagen / Gemini image, Adobe Firefly, Leonardo, Stable Diffusion (free, run locally or via a web UI).

## Image-to-video (step 4)
Needs: image input, 5-10s clips, good animal motion, 9:16 and 16:9 output.
Examples: Google Veo, Runway, Kling, Luma, Pika, Hailuo.

Some of these also generate speech with the video. If you use that, still keep the same voice description per animal.

## Text-to-speech (step 5)
Needs: Hindi and English, many voice styles, ability to save a voice and reuse it.
Examples: ElevenLabs, Google Cloud / Gemini TTS, Azure TTS, Play.ht.
Test a Hindi sample before choosing: quality varies between tools.

## Lip-sync (step 6)
Needs: works on animal faces (many are trained on humans; test first).
Examples: Hedra, HeyGen, Sync Labs, Runway lip-sync, Kling lip-sync.

## Video editing (step 7)
Examples: CapCut (easy, auto subtitles), DaVinci Resolve (free, powerful), Premiere Pro.

## Cost control
- Generate at low resolution/draft quality first, then upscale only the keepers.
- Plan shots so few clips need regenerating: one action per clip.
- Reuse clips, e.g. a lion walking shot can appear in several videos.
