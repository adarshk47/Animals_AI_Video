# Voices: Hindi and English

## Keep one voice per animal
Choose a voice for each animal once and write it in `characters/character-bible.md`. Use the same voice, speed and settings every video. Viewers recognise the lion by his voice.

## Choosing voices
| Animal | Look for |
|--------|----------|
| Lion | deep, slow, gravelly male |
| Monkey | high, fast, playful |
| Dog | warm, friendly, eager |
| Chimpanzee | mid-pitch, thoughtful |
| Pigeon | light, quick, a bit nervous |

If two animals sound too similar, change the pitch or pick a different voice. The audience must be able to tell speakers apart with eyes closed.

## Hindi vs English per scenario
Set the language in `templates/scenario.md`.
- Write Hindi lines in Devanagari script in the text-to-speech tool; this usually reads better than Roman Hindi (Hinglish).
- If a tool reads a word wrongly, respell it phonetically or add punctuation to change the pause.
- Test one line first before generating the full script.
- Use a voice that supports the language. A voice that sounds good in English may sound off in Hindi, so you may need a different voice name per language. The character bible has an (EN) and (HI) slot for this.

## Writing dialogue that works for animals
- Short lines. 5-12 words is best for lip-sync.
- Give each animal a verbal habit (lion: "Listen, little one..."; monkey: "Arre, arre, arre!").
- Add pauses with commas and full stops, rather than long sentences.
- Leave room for sound effects: a bark or roar between lines.

## Audio hygiene
- Export all voices at the same sample rate and similar loudness.
- Keep voice louder than music; duck the music during speech.
- Name files by shot: `shot03_lion.mp3`.

## Ethics and licensing
- Use voices that the tool licenses for your use.
- Do not clone a real person's voice without their permission.
